# Architecture decision records

`ADR-NNNN-<slug>.md` from `docs/ADR_TEMPLATE.md`, numbered globally, dated, never deleted (superseded ADRs get `Status: superseded by ADR-MMMM`). Program-level decisions (anything that changes `PROGRAM.md`, the shared `AGENTS.md` core, or `contracts/`) are written as `ADR-NNNN-PROGRAM-<slug>.md` and applied to both repositories.
