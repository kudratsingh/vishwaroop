# reports/

One report per accepted work order or phase, from `docs/REPORT_TEMPLATE.md`, named `<WO-id>-<slug>.md` or `<phase>-exit.md`. Reports are **append-only once merged**: later changes go in the dated **Errata** section at the end. `INDEX.md` is the one derived file here and may be regenerated.

Blockers are written as `BLOCKER-<YYYY-MM-DD>-<slug>.md` (`AGENTS.md §12`).

The starter's CPU validation (`VERIFICATION.md` at the repository root) does not establish any milestone; the first report is written by the first accepted work order.
